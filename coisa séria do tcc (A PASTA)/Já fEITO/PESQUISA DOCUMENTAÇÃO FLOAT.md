### ***Servidores e Banco de Dados:***

* ***WampServer:*** É um pacote de software para Windows que transforma o seu computador pessoal em um servidor de testes local. Ele instala de uma só vez o servidor web Apache, a linguagem PHP e o banco de dados MySQL. É indispensável para desenvolvedores web que precisam criar, testar e rodar sites complexos ou sistemas inteiros (como o WordPress) de forma offline antes de publicá-los na internet.
* ***MySQL Workbench:*** É a ferramenta visual oficial desenvolvida pela Oracle para gerenciar o banco de dados MySQL. Em vez de você gerenciar os dados digitando linhas de comando puras no terminal, ela oferece uma interface gráfica completa. Com ela, você pode criar tabelas de forma visual, desenhar diagramas de relacionamentos entre dados (modelagem de dados), fazer consultas complexas e administrar a performance do servidor de banco de dados.
* ***phpMyAdmin:*** É uma ferramenta web clássica e gratuita feita em PHP para administrar bancos de dados MySQL e MariaDB através de qualquer navegador de internet. Por ser muito leve e fácil de usar, ela vem pré-instalada em quase todos os serviços de hospedagem de sites do mundo. Permite criar tabelas, importar/exportar dados, apagar registros e rodar comandos SQL de forma rápida e direta, sem que você precise instalar nenhum programa pesado na sua máquina.
* ***DBeaver:*** É um gerenciador de banco de dados universal e de código aberto extremamente robusto. A grande vantagem dele sobre o MySQL Workbench é a versatilidade: enquanto o Workbench só mexe com MySQL, o DBeaver se conecta a praticamente qualquer banco de dados existente no mercado (como PostgreSQL, Oracle, SQL Server, MongoDB e SQLite). É a escolha ideal para desenvolvedores que trabalham com múltiplos projetos e diferentes tecnologias de armazenamento de dados na mesma máquina.



### ***Desenvolvimento, Controle de Versão e Criação de Apps:***

* ***Git:*** É um sistema de controle de versão distribuído que roda localmente no seu terminal ou prompt de comando. Ele funciona como uma "máquina do tempo" para o código-fonte de um projeto: cada alteração importante é registrada (via commit), permitindo que você desfaça erros, veja o histórico de quem escreveu cada linha e crie ramificações (branches) para testar novos recursos sem estragar a versão principal que já está funcionando.
* ***Android Studio:*** É o Ambiente de Desenvolvimento Integrado (IDE) oficial criado pelo Google para a criação de aplicativos voltados para o ecossistema Android (celulares, tablets, relógios e TVs). Ele inclui tudo o que um programador precisa: um editor de código inteligente para Java e Kotlin, ferramentas de design visual para arrastar botões na tela, e um emulador integrado para testar o aplicativo em um celular virtual diretamente no computador. É um programa pesado que exige computadores com bom desempenho.
* ***Visual Studio Code (VS Code):*** Criado pela Microsoft, é o editor de código leve mais popular do planeta. Ele não é um programa pesado como o Android Studio, mas sim um editor de texto altamente avançado e expansível. Através de milhares de extensões gratuitas, ele se adapta para programar em qualquer linguagem existente (Python, JavaScript, HTML, C++, etc.). Possui terminal embutido, integração nativa com o Git e ferramentas de preenchimento automático de código inteligente.



### ***Hospedagem, Compartilhamento e IA:***

* ***GitHub:*** É uma plataforma de hospedagem em nuvem desenvolvida sobre o sistema do Git. Ele serve como uma rede social e repositório central online para programadores. No GitHub, você armazena o histórico do seu código na nuvem para não perdê-lo, colabora com equipes do mundo inteiro gerenciando o que entra no projeto (via Pull Requests), monitora erros (via Issues) e expõe seu trabalho publicamente, funcionando como o portfólio oficial de um desenvolvedor para o mercado de trabalho.
* ***Vercel:*** É uma plataforma de nuvem focada em hospedagem rápida e automatizada de sites e aplicações web modernas (especialmente aquelas feitas com JavaScript e frameworks como React e Next.js). A mágica da Vercel é a integração com o GitHub: sempre que você atualiza o código no seu repositório online, a Vercel detecta a mudança de forma automática e atualiza o site que está no ar em poucos segundos, sem exigir configurações complexas de servidores.
* ***Runway:*** É uma plataforma pioneira de inteligência artificial generativa focada na criação e edição de mídias, principalmente vídeos e imagens profissionais. Utilizada por criadores de conteúdo, cineastas e designers, ela permite gerar cenas de vídeo realistas do zero apenas digitando um texto (text-to-video), transformar imagens estáticas em animações, remover fundos ou objetos indesejados de gravações com um clique e expandir o cenário de fotos usando IA na nuvem.



### ***Design e Diagramas:***

* ***Figma:*** É a ferramenta líder de mercado para o design de interfaces (UI) e experiência do usuário (UX). Rodando direto no navegador, ela permite que designers desenhem visualmente telas de aplicativos, sites e sistemas antes que qualquer linha de código seja escrita. O seu maior diferencial é o trabalho colaborativo em tempo real: várias pessoas podem mexer no mesmo layout ao mesmo tempo, deixar comentários e testar protótipos interativos onde os botões realmente simulam cliques.
* ***Adobe Photoshop CS6:*** É uma versão clássica e icônica (lançada originalmente em 2012) do software padrão da indústria para edição de imagens rasterizadas e manipulação digital. Embora seja uma versão antiga e que não possui os recursos modernos de IA da nuvem Adobe Creative Cloud, ela ainda é muito lembrada e utilizada por ser leve e eficiente para tratamentos fotográficos profissionais, criação de banners, retoques digitais, pinturas digitais e montagens complexas com camadas.
* ***Microsoft Visio:*** É um software corporativo especializado na criação de diagramas vetoriais, gráficos de dados e esquemas técnicos. Ele é amplamente utilizado em empresas para desenhar fluxogramas de processos de trabalho, organogramas de equipes, plantas baixas de escritórios, diagramas de redes de computadores e mapeamento de engenharia. Ele ajuda a transformar informações técnicas complexas em recursos visuais fáceis de entender.



### ***Formulários e Gestão:***

* ***Google Forms:*** É a ferramenta gratuita do ecossistema Google Workspace criada para o desenvolvimento de formulários, pesquisas de opinião, formulários de inscrição e testes de múltipla escolha online. O criador envia um link para os participantes e todas as respostas são coletadas automaticamente em tempo real, gerando gráficos estatísticos visuais ou organizando os dados diretamente dentro de uma planilha do Google Planilhas.
* ***Microsoft Forms:*** É a alternativa direta da Microsoft ao Google Forms, integrada ao ecossistema Microsoft 365. Ele cumpre o mesmo papel de criar questionários, exames e pesquisas de maneira rápida. É fortemente adotado no meio corporativo e em instituições de ensino que já utilizam ferramentas como o Microsoft Teams e o Excel, oferecendo recursos robustos de segurança de dados e integrações nativas com ferramentas de automação empresarial.
* ***Microsoft Project:*** É um software robusto de gerenciamento de projetos de alta complexidade. Ele não é apenas uma lista de tarefas, mas uma ferramenta científica para gerentes de projeto planejarem cronogramas detalhados, definirem dependências entre tarefas (o que precisa acabar para outra começar), gerenciarem a alocação de recursos humanos e financeiros, definirem linhas de base e acompanharem o progresso e os custos reais de grandes obras ou projetos corporativos.



### ***Navegadores e Textos Rápidos:***

* ***Bloco de Notas (Notepad):*** É o editor de texto puro mais minimalista e tradicional que vem embutido no sistema operacional Windows. Ele não possui opções de formatação como negrito, cores ou fontes variadas. Justamente por essa simplicidade extrema, ele é amplamente utilizado por profissionais de tecnologia e usuários comuns para limpar formatações de textos copiados da internet, fazer anotações rápidas e rascunhar códigos simples sem gerar arquivos pesados.
* ***Google Chrome:*** É o navegador de internet (browser) desenvolvido pelo Google e o mais utilizado globalmente. Ele se destaca pela velocidade de carregamento de páginas pesadas, estabilidade e pela imensa biblioteca de extensões da Chrome Web Store que adicionam novos recursos ao navegador. Ele possui ferramentas excelentes para desenvolvedores web inspecionarem códigos de sites em tempo real, além de sincronizar histórico e senhas com contas Google em celulares e PCs.
* ***Microsoft Edge:*** É o navegador oficial moderno integrado ao Windows, recriado sobre a mesma base de código do Chrome (o motor Chromium). Isso significa que ele é compatível com todas as extensões do Chrome, mas traz melhorias significativas de desempenho, menor consumo de memória RAM e de bateria no computador. Ele vem com ferramentas nativas de produtividade, como leitor de PDF avançado, captura de tela inteligente e assistentes de inteligência artificial integrados na barra lateral.
* ***Firefox:*** Desenvolvido pela Mozilla, é um navegador de internet independente e de código aberto, mantido por uma organização sem fins lucrativos. Ele se posiciona historicamente como o grande defensor da privacidade do usuário na web, trazendo bloqueadores nativos de rastreadores de anúncios e scripts de empresas de tecnologia. É altamente personalizável, seguro e a principal alternativa de mercado contra o monopólio técnico dos navegadores baseados em Chromium.



### Marcas de Estrutura e Dados (Não são linguagens de programação):

* ***HTML (HyperText Markup Language):*** É a linguagem de marcação que serve como o "esqueleto" de absolutamente qualquer página na internet. Ela não possui lógica (como contas matemáticas ou condições), mas define a estrutura e o conteúdo do site usando etiquetas (tags). É com o HTML que você avisa ao navegador onde fica um parágrafo, um título, uma imagem, um link ou um formulário. Sem ele, a web visual não existiria.
* ***XML (eXtensible Markup Language):*** É uma linguagem de marcação criada puramente para armazenar, organizar e transportar dados de forma que tanto humanos quanto computadores consigam ler facilmente. Ao contrário do HTML, ela não serve para exibir páginas bonitas no navegador, mas sim para estruturar informações de forma rígida através de etiquetas personalizadas. É muito usada em configurações de sistemas antigos, integração de softwares e na emissão de Notas Fiscais Eletrônicas (NF-e) no Brasil.



### Estilização e Design (Visual):

* ***CSS (Cascading Style Sheets):*** É a linguagem de estilos usada para dar beleza, cores e vida ao esqueleto de HTML. Enquanto o HTML coloca o texto e o botão na tela, o CSS define que a cor do fundo será escura, o tamanho da letra será maior, o botão terá cantos arredondados e o layout se adaptará perfeitamente a telas de celulares (responsividade). É o que transforma uma página de texto puro em uma interface profissional.
* ***Tailwind CSS:*** É um framework (um conjunto de ferramentas prontas) baseado em CSS que acelera drasticamente o trabalho do desenvolvedor. Em vez de você criar um arquivo separado e escrever dezenas de linhas de CSS tradicional para estilizar um botão, o Tailwind oferece "classes utilitárias" prontas que você joga direto no seu HTML (como bg-blue-500 text-white font-bold py-2 px-4 rounded). Isso torna o desenvolvimento visual muito mais rápido, padronizado e fácil de manter.



### Programação e Lógica no Navegador (Front-End):

* ***JS / JavaScript:*** É a linguagem de programação mais popular do mundo, responsável por trazer interatividade, lógica e dinamismo para as páginas web. Enquanto o HTML estrutura e o CSS embeleza, o JavaScript faz as coisas "acontecerem" sem que o usuário precise recarregar a página. É ele quem controla animações complexas, atualiza o feed de uma rede social em tempo real, valida se uma senha digitada está correta e cria sistemas web completos.
* ***React / React.js:*** É uma biblioteca de JavaScript criada pelo Facebook para construir interfaces de usuário de forma moderna e extremamente rápida. Em vez de criar páginas inteiras do zero, o React permite que você quebre o site em pequenos pedaços reutilizáveis chamados "Componentes" (como um componente de botão, um de barra de navegação ou um de card de produto). Ele atualiza apenas a parte da tela que sofreu alteração de dados, deixando a navegação instantânea e fluida como um aplicativo de celular.



### Programação no Servidor (Back-End):

* ***PHP (Hypertext Preprocessor):*** É uma linguagem de programação focada no desenvolvimento web do lado do servidor (Back-End). Quando você acessa um site em PHP, o código roda em um servidor distante para processar dados (como verificar se a sua senha de login está certa no banco de dados ou buscar produtos de uma loja) e devolve apenas o HTML pronto para o seu navegador. É a linguagem que dá vida ao WordPress (que move mais de 40% da internet mundial), sendo muito famosa pela facilidade de conexão com bancos de dados como o MySQL.
* ***Java:*** É uma das linguagens de programação mais robustas, maduras e utilizadas do mercado corporativo global. Ela funciona sob o lema "escreva uma vez, rode em qualquer lugar" graças à Máquina Virtual Java (JVM). É amplamente utilizada por grandes bancos, sistemas de multinacionais, aplicações de alta segurança e, historicamente, foi a base principal para a criação de aplicativos móveis dentro do Android Studio. É uma linguagem fortemente tipada e focada em Programação Orientada a Objetos (POO).
